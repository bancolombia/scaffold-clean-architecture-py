# CLI Contract: `gep --type mcp --add-tool` (Incremental MCP Tool Addition)

**Feature**: `021-mcp-add-tool`
**Command**: `scaffold generate-entry-point` / `scaffold gep`
**Scope**: New `--add-tool` flag and its dependent options; the no-flag `gep --type mcp` creation path is unchanged

---

## Command Signature

```
scaffold gep --type mcp --add-tool --name <snake_case_name> \
  [--param <name:type>]... [--returns <type>] [--description <text>] [--dry-run]

scaffold generate-entry-point --type mcp --add-tool --name <snake_case_name> \
  [--param <name:type>]... [--returns <type>] [--description <text>] [--dry-run]
```

---

## New Flags

| Flag | Type | Repeatable | Default | Valid with | Description |
|------|------|------------|---------|-------------|-------------|
| `--add-tool` | bool (flag) | no | `False` | `--type mcp` only | Append one new tool stub to an existing MCP entry point instead of creating one |
| `--name` | str | no | — (required with `--add-tool`) | `--add-tool` | New tool's name; snake_case |
| `--param` | str (`name:type`) | **yes** | none (zero params) | `--add-tool` | One typed parameter for the new tool; repeat for multiple |
| `--returns` | str | no | `"str"` | `--add-tool` | Return type-expression for the new tool |
| `--description` | str | no | generic placeholder | `--add-tool` | Docstring for the new tool |

### Existing flags (unchanged by this feature)

| Flag | Valid with `--add-tool` | Notes |
|------|--------------------------|-------|
| `--type` | Only `mcp` | Any other value (or omission) is rejected (FR-012) |
| `--swagger` | No | Creation-only, restapi-specific |
| `--enable-kafka` | No | Creation-only, agent-specific |
| `--enable-mcp-client` | No | Creation-only |
| `--with-resources` | No | Creation-only |
| `--with-prompts` | No | Creation-only |
| `--dry-run` | Yes | Previews the insertion without writing to disk |

---

## Guard Rules (evaluated in order, first failure wins)

1. **`--add-tool` + incompatible `--type`** (FR-012)
   ```
   Error: --add-tool is only valid with --type mcp.
   ```
   Exit code: `1`

2. **`--add-tool` + any creation-only flag** (FR-011)
   ```
   Error: --add-tool is incompatible with --with-resources.
   ```
   (one message per first offending flag encountered: `--swagger`, `--enable-kafka`, `--enable-mcp-client`, `--with-resources`, `--with-prompts`)
   Exit code: `1`

3. **`--add-tool` without `--name`** (FR-002)
   ```
   Error: --name is required with --add-tool.
   ```
   Exit code: `1`

4. **Invalid `--name`** (FR-003)
   ```
   Error: Invalid name 'CreateFile'. Use snake_case (e.g., 'create_order').
   Error: Invalid name 'class'. 'class' is a Python keyword and cannot be used as a tool name.
   ```
   Hard keywords only (`keyword.iskeyword`); soft keywords such as `match` or `type` are accepted.
   Exit code: `1`

5. **Invalid `--param`** — bad format, bad name, or bad type (FR-005)
   ```
   Error: Invalid --param 'Path:str'. Parameter name must be snake_case (e.g., 'path:str').
   Error: Invalid --param 'path:print("x")'. 'print("x")' is not a recognizable type-expression.
   Error: Invalid --param 'path'. Expected 'name:type' format.
   Error: Invalid --param 'class:str'. 'class' is a Python keyword and cannot be used as a parameter name.
   ```
   Exit code: `1`

6. **Duplicate `--param` names** (FR-006)
   ```
   Error: Duplicate --param name 'path'. Each parameter name must be unique.
   ```
   Exit code: `1`

7. **Invalid `--returns`** (FR-007)
   ```
   Error: Invalid --returns 'print("x")'. Not a recognizable type-expression.
   ```
   Exit code: `1`

8. **Unsafe `--description`** (FR-008)
   ```
   Error: --description contains an embedded triple-quote sequence and cannot be used as a docstring.
   ```
   Exit code: `1`

9. **MCP entry point does not exist** (FR-009) — checked only after all of the above pass, before project-content guards
   ```
   Error: No MCP entry point found at infrastructure/entry_points/mcp_server/.
   Hint: Run `scaffold gep --type mcp` first to create one.
   ```
   Exit code: `1`

10. **Unsupported / legacy project (`bind_tools` missing or not the last top-level statement)** (FR-017)
    ```
    Error: infrastructure/entry_points/mcp_server/tools.py was generated by an older scaffold
    version and does not support --add-tool.
    Hint: Make `async def bind_tools` the last function in tools.py, or regenerate the entry point
    (back up any custom tools first) with `scaffold gep --type mcp`.
    ```
    Exit code: `1`

10b. **Missing or unrecognized `test_tools.py`** (FR-017) — file absent, unreadable, or lacking a top-level `_make_mock_mcp` helper and imports of `bind_tools` and `asyncio`
    ```
    Error: tests/infrastructure/entry_points/mcp_server/test_tools.py is missing or does not have
    the structure --add-tool needs to append a registration test.
    Hint: Restore test_tools.py, or regenerate the entry point with `scaffold gep --type mcp`.
    ```
    Exit code: `1`

11. **Duplicate tool name** (FR-010) — `--name` matches a registered `@mcp.tool("…")` name, a function name defined inside `bind_tools`, or the reserved name `bind_tools`
    ```
    Error: A tool named 'create_file' already exists in tools.py.
    Error: 'bind_tools' is reserved by the tool-binding function and cannot be used as a tool name.
    ```
    The second form is used only for the reserved name `bind_tools`.
    Exit code: `1`

12. **Target file not writable** (FR-019) — checked after all of the above, before any write
    ```
    Error: Cannot write to tests/infrastructure/entry_points/mcp_server/test_tools.py.
    Hint: Check the file's permissions and re-run the command.
    ```
    Exit code: `1`

13. **Write failure during persist** (FR-019) — any file already modified is restored to its original contents
    ```
    Error: Failed to write test_tools.py (<OS error>). tools.py was restored; no changes were made.
    Hint: Fix the underlying problem (permissions, disk space) and re-run the command.
    ```
    Exit code: `1`

## Output: File Mutated

```text
src/<pkg>/
└── infrastructure/
    └── entry_points/
        └── mcp_server/
            └── tools.py                               ← MODIFIED (one new tool stub appended)

tests/
└── infrastructure/
    └── entry_points/
        └── mcp_server/
            └── test_tools.py                           ← MODIFIED (one new registration test appended)
```

No other file is created, modified, or deleted. No dependency is added to `pyproject.toml`.

---

## Generated Snippet — `tools.py` (example)

For `--name create_file --param path:str --param content:str --returns str --description "Creates a file on disk"`:

```python
    @mcp.tool("create_file")
    async def create_file(path: str, content: str) -> str:
        """Creates a file on disk"""
        raise NotImplementedError("Tool 'create_file' is not yet implemented.")
```

With no `--param`, no `--returns`, no `--description`:

```python
    @mcp.tool("create_file")
    async def create_file() -> str:
        """TODO: describe this tool."""
        raise NotImplementedError("Tool 'create_file' is not yet implemented.")
```

## Generated Snippet — `test_tools.py` (example)

```python
def test_bind_tools_registers_create_file() -> None:
    """Calling bind_tools registers 'create_file' on the mcp instance."""
    mock_mcp, registered = _make_mock_mcp()
    fn = getattr(bind_tools, "__wrapped__", bind_tools)
    asyncio.run(fn(mock_mcp))
    assert "create_file" in registered
```

---

## Dry-Run Output Contract

When `--add-tool --dry-run` is used and all guards pass, the command MUST:

1. Print which file(s) would be modified (`tools.py`, `test_tools.py`).
2. Print the exact snippet that would be inserted into each file (syntax-highlighted), identical byte-for-byte to what a non-dry-run invocation would insert.
3. Write nothing to disk.
4. Exit code: `0`.

When any guard fails, the guard's error takes precedence over the dry-run preview — no partial preview is shown (see Edge Cases in `spec.md`).

---

## Backward Compatibility

- `scaffold gep --type mcp` with no `--add-tool` continues to behave exactly as before (full entry-point creation); this contract does not alter that path.
- Projects (created by an earlier scaffold version, or hand-edited) that do not have `async def bind_tools` as the last top-level statement in `tools.py` will hit guard rule 10 above until fixed or regenerated.
